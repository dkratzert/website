StructureFinder

The purpose of StructureFinder is to find crystallographic files such as Crystallographic Information Files (.cif) and SHELX (.res) files. StructureFinder indexes all .cif and/or .res files below a certain directory or directories and makes them searchable. The intention is not to bring the files in order or maintain a static database — it only reflects the order on the file system.
